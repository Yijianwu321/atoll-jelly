玩法 ？

  • 按住水面：手指按压出涟漪，拖动划出尾迹，快速一抽溅起水花
  • 拖动空白处：环绕视角；滚轮 / 双指捏合：缩放
  • 拖动果冻侧壁或右键拖动：倾斜方块（最大 5.2°），松手看晃动
  • 点住游泳圈：拿起，可放回水面、浮台或沙滩

移动端用手指抽动，支持触屏环绕/双指缩放，不支持 WebGPU 时显示降级提示卡，页面不滚动，控制台无报错。

此设备暂不支持 WebGPU

「环礁 / 果冻」使用原生 WebGPU + WGSL 渲染。当前浏览器没有可用的 WebGPU 适配器，所以这里只显示静态的果冻切面示意；水体、鱼群与水上飞机的模拟仍在后台以纯 JS 运行。

请使用最新版 Chrome / Edge（113+）或 Safari 18+，并确认已开启硬件加速。
